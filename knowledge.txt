Seven Kids Code Foundation is a kids coding and robotics program in Ghana. We teach children real tech skills through fun, hands-on classes.

Website: sevenkidscodefoundation.org

What We Teach:
- Python Programming: Real-world coding challenges with the world's most popular language
- Scratch: Block-based coding for animations and games
- Roblox Game Development: Create 3D worlds and learn Lua programming
- Arduino: Build smart gadgets and connect code to the physical world
- Blender: 3D modeling, animation, and character design
- Typing Master: Keyboard skills and productivity
- Robotics: Build real robots and solve problems step-by-step
- AI and Machine Learning: Hands-on AI projects
- Web Development and Design: Create websites
- 3D Printing Model Design: Design and print 3D models
- Game Development: Create your own games

Who It's For:
Kids and teens who want to learn coding, robotics, and tech skills. Classes focus on teamwork, creativity, critical thinking, and building confidence.
